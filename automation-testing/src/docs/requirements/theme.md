# THEME — Sáng / tối và giảm chuyển động

- **REQ-THEME-01** Mặc định giao diện theo hệ điều hành (`Theo hệ thống`) và đổi ngay khi hệ đổi (FR-12).
- **REQ-THEME-02** Nút giao diện xoay vòng `Theo hệ thống → Nền sáng → Nền tối → Theo hệ thống`, có nhãn chữ thấy được và `aria-label` nói trạng thái hiện tại (FR-12, ux-feedback F-04).
- **REQ-THEME-03** Lựa chọn rõ ràng thắng hệ điều hành, được nhớ qua tải lại, và áp cho cả màn chơi (FR-12, README "or you can pin one").
- **REQ-THEME-04** `prefers-reduced-motion` đưa chuyển động về 0 — nhân vật và thùng không trượt nữa — mà game vẫn chơi được (FR-12, NFR-A11Y-05).
